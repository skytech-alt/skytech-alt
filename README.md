## 🚀 Экосистема проектов / Project ecosystem

### 🧠 SkyForge — язык программирования с русским синтаксисом

> 📦 `skytech-alt`

Русскоязычный язык программирования, написанный на Python. Имеет собственный лексер, парсер и интерпретатор, а также транспилятор в Python AST — ускорение до **130×** на рекурсивных вычислениях.

- ООП, `async/await`, генераторы, pattern matching, декораторы, исключения
- Python-мост: доступ ко всему PyPI из SkyForge
- Веб-фреймворк, ORM, тестовый фреймворк
- LSP-сервер для VS Code (`skyforge-lsp`)

### 🏰 SkyCitadel — зашифрованная цифровая экосистема

> 📦 `SkyMonder`

Открытая альтернатива YouTube, VK и Telegram: видеохостинг, E2EE-мессенджер, соцсеть, карты, радио, погода, новости и музыка в одном месте. Всё содержимое шифруется на стороне клиента (**AES-256-GCM**), встроенный прокси обходит блокировки.

- Видеохостинг без рекламы и цензуры
- Приватный мессенджер с E2EE, аудио/видеозвонками
- Соцсеть, карты, радио, погода, музыка
- Устойчивость к блокировкам и самохостинг
